# Crossio web tools

Crossio's website presents the Android crosshair overlay app and provides a browser-based crosshair design tool. Visitors can try a shape on the landing page and continue in a dedicated layered editor.

The editor serves people building geometric reticles for transparent PNG export. Projects stay in the browser's local storage and can be exchanged as editable JSON files. No account, server storage or app-code compatibility is required. The first release excludes undo/redo, image layers and freehand paths.

The accepted workflow is add elements, arrange independent layers, refine properties, inspect against different backgrounds, then save or export. Both Turkish and English, touch and keyboard, and light and dark themes are supported.
